From download
to your first set.

Install the Android build directly, open OMEGA, and start shaping your routine. Three steps, zero friction.

01

Download the APK

Tap the download button to grab the latest ARM64 release directly from GitHub Releases. Around 19.6 MB — smaller than a single Instagram story.

02

Allow the install

Android may ask you to allow your browser to install apps from this source. This is a standard one-time permission you can revoke later in Settings.

03

Open and start lifting

Create your training split, configure your rest timer, and log your first session. No sign-up, no cloud sync, no onboarding carousel.

⚠

About Android's install prompt: Android shows a warning for apps installed outside Google Play. This is standard behavior for all sideloaded APKs. OMEGA is fully open-source — review the code and release artifacts on GitHub before installing.

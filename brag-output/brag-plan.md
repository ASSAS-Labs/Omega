# Brag Plan: OMEGA

## What is this app?
A local-first, privacy-focused workout tracker and progressive overload manager built with React Native and SQLite — with zero cloud accounts, zero ads, zero telemetry, and 179 passing automated tests.

## The angle
Engineering rigor meets fitness. In a world where workout trackers require $15/month subscriptions, constant internet connections, and sell your biometric data, OMEGA runs 100% offline with hardened SQLite WAL concurrency, instant 1RM formulas, and zero latency.

## Hook (first 2-3 seconds)
High-impact dark typography:
"NO CLOUD. NO ACCOUNTS. NO PAYWALLS."
Snap transition into:
"JUST PURE PROGRESSIVE OVERLOAD."

## Key moments (the middle)
- **The Dashboard & Streak**: Interactive 5-day streak counter with emerald compliance strip and instant session launch.
- **Local-First SQLite Engine**: WAL mode concurrency, zero network lag, atomic backups, 100% offline privacy.
- **Real Analytics & 1RM Progression**: Epley formula calculations, 30% chart headroom, instant volume breakdown.
- **Battle-Tested Reliability**: 12 test suites, 179 passing automated tests, 100% domain coverage.

## Outro / punchline
"Your strength data belongs to you."
Final OMEGA branding, 100% Local-First badge, and PolyForm Noncommercial license.

## User flow worth showing
1. View 7-day compliance strip & streak counter on the sleek dark dashboard.
2. Log exercises with instant local SQLite writes.
3. Inspect interactive 1RM progression and volume trends across sessions and weeks.
